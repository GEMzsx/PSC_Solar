# 首版字段字典与清洗规则

依据[官方字段说明 v5.4](https://github.com/Jesperkemist/perovskitedatabase/blob/master/Perovskite_webpage_version_1/static/files/The%20perovskite%20database%20description%20of%20data%20content%205.4.pdf)，读取其中通用编码规则以及组成、溶剂、退火、面积、光照和 PCE 的说明。

## 编码和单位

`|` 分隔器件层，`>>` 分隔制备步骤，`;` 分隔同一步中的材料或退火程序阶段。材料和相应比例必须逐项对齐。首版只接收单层、单步、单阶段退火记录，不把多阶段程序压缩成平均值。

- 退火温度：°C；退火时间：min。
- 测量面积：cm²。历史采集可能在未报告面积时使用 0.1 cm² 默认值，不能把非空视为实验确认。
- 标准光强：100 mW/cm²；光谱限定 AM 1.5。
- PCE：百分数；误差与区间宽度使用“百分点”。
- 原数据库 FF：0–1，不是百分数。组内模板明确记录 `ff_fraction`。
- 溶剂混合比：官方优先使用体积比，但允许质量或摩尔比。本模型按记录数值归一化，称为“记录比例份额”，不能宣称全部为体积分数。组内模板新增 `solvent_ratio_basis` 消除歧义。

## 清洗范围

固定 nip 架构、单步 Spin-coating、Pb 单一 B 位、AM 1.5 与 100 mW/cm²；PCE 采用 `JV_default_PCE_scan_direction == Reversed`，避免将稳定态和不同扫描方向混在同一标签中。PCE 0–100 为基础合法范围，保留 0% 失败器件。

A 位限定 Cs/FA/MA，系数总和 0.8–1.2；X 位限定 I/Br，总和 2.5–3.5；Pb 系数 0.95–1.05。系数按总和归一化；这些容差属于首版范围规则，不是晶体化学定律，非化学计量效应暂未建模。

溶剂限定 DMF、DMSO、GBL、NMP，记录比例非负且总和大于零，逐项归一化。未知配比、多层或多步记录排除。退火必须为单一数值，温度 -10–400°C、时间 0–1440 min。测量面积限定 0–1 cm²，不包含 0。这是小面积演示模型，不能验证大面积制备能力。

排除清单保留原始 CSV 行号与首个排除原因；行号包含表头，从 2 开始。一个记录可能违反多个条件，排除统计不表示各条件的独立缺失量。

## 标准化预测字段

数值字段：`a_cs`、`a_fa`、`a_ma`（A 位份额，和为 1）；`x_br`、`x_i`（X 位份额，和为 1）；`solvent_dmf`、`solvent_dmso`、`solvent_gbl`、`solvent_nmp`（记录比例份额，和为 1）；`anneal_temperature_c`、`anneal_time_min`、`area_cm2`。

类别字段：`etl`、`htl`、`quenching_media`、`additives`。未知与空值统一为 `Unreported`；这并不证明没有添加剂或没有反溶剂。

标签 `pce`、来源 `doi` 和 `source_row` 不作为输入。Voc、Jsc、FF、稳定态效率、其他扫描效率、寿命、表征后的带隙/厚度和发表时间均不作为模型特征。

## 划分与复现

同一论文内完全相同的特征与标签记录仅保留首条；不同性能的相同配方保留。跨论文完全相同的特征与标签将连接成一个独立分组，保证这些重复记录不跨训练、验证、校准和测试集合。连接分组不会消除重复记录的统计权重，这仍是数据限制。

四个集合约按独立分组的 60%/15%/10%/15% 分配，实际记录数比例可以不同。训练集学习标准化和类别编码，验证集选择模型，校准集估计区间，测试集只用于最终评价。

区间使用校准分组的最大绝对残差，有限样本分位数对应 90% 的新分组覆盖目标。需要论文分组及其规模具有可交换性；跨实验室、跨工艺或特定配方覆盖没有保证。区间上下限不裁剪，因此可能出现负下限；这表示模型分辨力不足，不表示物理上负效率。

## 实验记录模板

使用 [experiment_record.csv](../templates/experiment_record.csv)，一行对应一个测量器件，重复器件使用相同批次号与不同样本编号。若记录的是均值，应在 notes 说明样本数和标准差，不与单器件记录混淆。`status` 区分成功、失败、未测，缺测值留空，不能用 0 替代。

实验导入命令 `python -m psc_solar ingest --input 填写后的实验记录.csv` 校验并合并到本地 `data/lab/experiments.csv`，相同编号的相同记录跳过，冲突记录停止整个导入，未测和失败实验均保留。`model_inputs.csv` 输出符合当前模型范围且已有 PCE 的记录；`eligibility.csv` 保存所有样本的适用性与原因。组内预测接口要求已确认的 volume 溶剂配比，其他口径保留为实验记录但暂不接入模型。

模板必填 `sample_id`、`batch_id`、`operator`、ISO 格式 `date`、`source` 和 `status`；status 使用 `success`、`failed`、`unmeasured`。success 需有 PCE，failed 需说明原因，unmeasured 不得填 PCE。未测不等于 0%，失败且实测为 0% 的记录可以进入适用子集。

主记录采用完整写入临时文件后替换，避免半个 CSV 覆盖旧库。三个派生文件不是跨文件事务；若写入中断，应检查主记录并重新运行同一导入以重建派生文件。当前不会自动将组内数据混入公开训练集或重训模型，需先核实实验域与足够的独立校准批次。薄膜质量表征字段暂为采集接口，当前模型没有训练薄膜质量预测。
