# PSC Solar：钙钛矿太阳能电池工艺预测与优化

面向钙钛矿太阳能电池大面积可控制备，构建在普通笔记本上运行的小样本预测与优化工具。结合实验数据和溶剂物理化学描述符，研究工艺参数、薄膜质量与器件性能之间的关联，并通过实验反馈迭代模型。

## 项目目标

- 预测器件 PCE，并给出经过验证的预测区间。
- 分析影响性能的关键组分与工艺因素。
- 搜索对参数波动具有容忍度的稳健工艺窗口。
- 推荐下一批实验条件，形成“预测—验证—更新”的闭环。
- 提供标准化实验记录模板与组内可使用的软件工具。

项目以软件建模和数据处理为边界，预留原位监测数据接口。薄膜质量预测的具体指标将根据组内表征条件确定。

## 首版建议范围

当前模型限定 nip、单层铅基、单步旋涂、单阶段退火、0–1 cm² 小面积器件；A 位为 Cs/FA/MA，X 位为 I/Br，溶剂为 DMF/DMSO/GBL/NMP。标签口径限定 AM 1.5、100 mW/cm² 下的反向扫描 PCE。

输入限于预测时已知的组分、工艺和器件背景信息。Voc、Jsc、FF 直接参与 PCE 的计算，不作为首版 PCE 模型输入。评价优先按论文或实验批次分组，避免同源数据泄漏。

首版范围已于 2026-10-02 确认，详细边界见[首版范围确认稿](./首版范围确认稿.md)。

## 快速运行

本机已建立 `.venv` 并完成训练。项目根目录下使用 PowerShell：

```powershell
# 启动本地网页，访问 http://127.0.0.1:8501
./scripts/run.ps1

# 全流程清洗、训练和评价（更新 artifacts/baseline 与 data/processed）
./scripts/run.ps1 -Action train

# 50、100、200 条样本预演
./scripts/run.ps1 -Action small-sample

# 数据、推理和表单交互测试
./scripts/run.ps1 -Action test

# 命令行批量预测
./.venv/Scripts/python.exe -X utf8 -m psc_solar predict --input artifacts/baseline/example_input.csv --output artifacts/baseline/example_prediction.csv

# 合并填写后的实验记录（默认存入本地 data/lab，不自动重训）
./.venv/Scripts/python.exe -X utf8 -m psc_solar ingest --input 填写后的实验记录.csv
```

在另一台机器上，先准备带 pip 的 Python 3.12，再建立环境和下载数据：

```powershell
./scripts/setup.ps1 -PythonPath 'C:/path/to/python.exe'
./scripts/download_data.ps1
./scripts/run.ps1 -Action train
./scripts/run.ps1 -Action small-sample
./scripts/run.ps1
```

本机可直接运行 `./scripts/setup.ps1`，自动优先使用 Codex 内置 Python。依赖安装仅写入项目 `.venv`。当前核心依赖版本固定在 `requirements.txt`；模型加载应使用同版本环境。

## 首轮训练结果

固定随机种子 42。训练集 6,028 条，验证集 1,408 条，校准集 1,053 条，测试集 1,424 条。论文及跨论文重复记录连接分组均不跨集合。

比较均值基线、岭回归和两种叶节点大小的 Extra Trees，按验证集的论文等权 MAE 选择 `extra_trees_leaf_3`，测试集只做最终评价。

- 独立测试 MAE：3.074 个百分点；均值基线 4.033 个百分点。
- 独立测试 RMSE：4.083 个百分点；R²：0.289。
- 预测排名前 25% 的高性能命中率：55.06%；随机期望 25%。尚未进行显著性检验。
- 区间名义目标：新独立论文分组 90% 覆盖。实测分组全部样本覆盖率 92.26%，行覆盖率 97.68%。
- 固定预测区间约 ±9.91 个百分点，较宽；不能据此精确承诺某个配方的效率或保证工艺窗口达标。

公开数据 50/100/200 条样本预演中，树模型三次采样的验证 MAE 均值分别为 4.17/4.14/3.93 个百分点。结果见 `artifacts/baseline/small_sample_results.csv`，不代表组内小样本精度。

## 工艺探索的解释

网页中提交配方后，可以固定组分、溶剂、面积和类别参数，搜索退火温度与时间。仅保留有相近历史记录支持、且扰动后仍位于训练范围内的候选。温度默认扰动 ±5°C，时间默认 ±10%。

模型窗口条件是所有所检查扰动点的区间下界达到目标 PCE；若没有满足条件的点，明确报告未找到窗口。有限网格不能证明整个连续区域稳健。

实验建议交替考虑保守性能和树模型分歧/新颖性，避免紧邻已测点及候选扎堆。分歧是探索代理指标，尚未证明信息增益，也未通过真实闭环实验验证。实验允许的参数边界仍应由课题组确认。

## 数据与复现约定

- 原始数据保留来源、版本、单位和样本标识，清洗结果可追溯。
- 组内数据的共享范围按课题组要求确认。
- 训练记录保存数据划分、配置和随机种子。
- 示例或模拟数据明确标注，不作为真实实验成果。

当前预测模型不包含薄膜质量中间层、溶剂物理描述符、涂布速度/湿度等缺失严重的参数。已提供组内记录校验与合并接口，尚未验证组内模型重训与真实闭环；实验记录模板用于先收集这些数据。归因结果属于关联分析，不能证明因果关系；本次退火温度的重要性较弱，未达到原需求中的文献机理 sanity check。
